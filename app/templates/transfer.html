Account / Export and import

Export

One file with everything this portal holds: {{ routers }} router{{ "s" if routers != 1 }} and their backups, managed settings, {{ users }} user{{ "s" if users != 1 }}, the SSH key the routers trust, and the key that decrypts backups. Anyone who can read it controls the routers, so it is encrypted with a passphrase you choose here. The passphrase is not stored; without it the file cannot be opened.

Import

Replaces everything in this portal with the contents of an export: routers, backups, settings and users. You are signed out and sign in again with a user from the export. The data being replaced is moved to a before-import-… folder in the data volume, not deleted. Stop the portal the export came from, so two portals do not manage the same routers.
